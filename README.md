# 🚀 SaraGalaxy - Mystery Life Edition

Un juego arcade espacial retro desarrollado en **HTML5 + Canvas + JavaScript Vanilla**, inspirado en los clásicos shooters de SEGA con mecánicas modernas de riesgo y recompensa mediante cajas misteriosas.

---

## 🎮 Gameplay

Controlás una nave espacial y debés sobrevivir a oleadas infinitas de enemigos mientras aumentás tu puntaje y avanzás de nivel.

Las cajas misteriosas pueden darte:

- 🔫 **MEGA BALA**
- ☣️ **VIRUS**
- 💥 **TRAMPA**
- 💙 **VIDA EXTRA**

Cada partida es diferente.

---

## ✨ Características

- 🌌 Fondo espacial animado
- 👾 Enemigos progresivos
- 👑 Boss fights
- 🎵 Música retro generada por Web Audio API
- 📱 Compatibilidad mobile con joystick táctil
- 🏆 Ranking local con `localStorage`
- 💥 Partículas y explosiones
- ⚡ Power-ups y debuffs temporales
- 🎨 Estética cyber-retro
